# 0028 — 正确性裁判与越界处置（阶段一：只标注不阻断）

**What to build:** 自洽性核验只证明模型说了真话，不证明它干的是用户要的事——「改 A 动了 B」按区域判定，代码判定不了。轮末由一个独立裁判比对用户原话与代码已经算好的真实 diff（hunk 附行号，不让裁判自己数行），判定改动是范围内、越界、还是未完成。越界时卡片列出具体文件与行区间并标红，交用户裁决接受或回滚；未完成只标注、照常留档。裁判看不到智能体的任何自述——否则退化为让模型给自己打分。**本工单只做阶段一：只标注不阻断，越界轮照常留档快照**，先在无破坏力的位置上收集真实误判率；「越界轮不留档」是阶段二的一次开关翻转，待数据出来后单开一张工单。遵循 ADR 0005「第 8 层」段与规格 0021。

**Blocked by:** 0027（共用辅助模型注入点；卡片徽标与迭代日志核验结论字段已就位）

**Status:** done

- [x] 仅在改动代码轮且磁盘真有改动时触发裁判；咨询轮与零改动轮不触发、不产生任何调用成本（0030 修订：分类 modify_code 且以 no_change 收尾的「可疑零改动轮」带空 diff 照常进裁判；咨询轮、首建轮与分类缺席的零改动轮仍不触发）
- [x] 裁判输入为：用户原话 + 最近若干轮上下文 + 代码算好的 diff（hunk 由标准库定位并附行号）
- [x] 裁判输入不得包含智能体的任何自述：总结、自报意图、声明改动文件、分类器产出的用户目标，全部不给
- [x] 裁判输出裁决（范围内 / 越界 / 未完成）与越界段落清单（文件、行区间、理由）
- [x] 越界 → 卡片列出越界段落并标红，提示用户可接受（越界改动会被下一次成功轮的快照自然吸收）或回滚上一版；**阶段一仍照常留档快照**
- [x] 未完成 → 卡片标注未完成，照常留档快照（改动合法、只是没做完，不该惩罚）
- [x] 范围内 → 干净收尾，无任何额外打扰
- [x] 不做裁判自动回滚越界段落，也不把裁决回喂让模型自动返工（不可逆的破坏性操作不得建立在概率判断上；模型自纠越界极易引入新的越界）
- [x] 裁判失败（网络 / 超时 / 非法输出）→ 复用既有重试次数与退避语义重试一次，仍失败则卡片标注「核验未完成」且快照照建——安全网故障不得扣住用户的劳动成果，且必须显式化而非静默吞掉
- [x] 裁判裁决写入迭代日志的核验结论字段
- [x] 裁判不消耗生成名额
- [x] 裁判走辅助模型注入点；本次不切小模型（辅助模型配置项默认等于主模型）
- [x] 测试使用 fake 模型，覆盖三种裁决值、裁判失败降级为「核验未完成」且快照照建、以及「裁判不得看见智能体自述」这条性质（在工程师总结里塞一个唯一标记串，断言它不出现在裁判收到的消息里）
- [x] 阶段二（越界轮不留档快照）明确不在本工单范围内
