# 10 — 团队模式两阶段生成

**What to build:** 创建项目时可选团队模式：产品经理智能体先流式产出 PRD，以可交互卡片呈现；用户确认通过或追加修改意见后，工程师智能体才开始实现。PRD、确认与意见全部落对话历史，重新打开项目可回看。

**Blocked by:** 03（工程师模式生成主链路）

**Status:** done

- [x] 创建项目时可选择工程师模式或团队模式，模式在项目信息中可见
- [x] 团队模式首条消息产出 PRD（SSE prd 事件），前端渲染为带“确认/追加意见”操作的卡片
- [x] 用户确认（可附意见）后工程师智能体开始生成，后续迭代体验与工程师模式一致
- [x] 未确认 PRD 前发送普通消息会被引导先处理 PRD
- [x] PRD 与确认消息持久化于对话历史
