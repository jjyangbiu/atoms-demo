# 05 — 预览托管

**What to build:** 让生成的应用"看得见、跑得起来"：项目属主登录后，在项目页右侧预览区通过 iframe 看到自己应用的真实运行效果；迭代完成后预览自动刷新到最新版本。预览路径受登录与属主双重校验。

- [x] 生成/迭代完成后前端预览自动指向最新版本
