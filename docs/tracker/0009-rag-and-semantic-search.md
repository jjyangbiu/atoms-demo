# 09 — 模板知识库 RAG + 画廊语义搜索

**What to build:** 给智能体装上"参考资料"、给画廊装上"意图搜索"：预置 10~15 条手写模板知识条目（应用模板 + 通用技术片段）灌入 Milvus Lite（embo-01 向量化），智能体生成前经 `search_templates` 工具检索相关模板注入上下文；App 世界支持语义搜索（"记账工具"能找到相关应用）；优质已发布应用沉淀回知识库，形成闭环。

**Blocked by:** 03（工程师模式生成主链路）、08（App 世界画廊与克隆）

**Status:** ready-for-agent

- [ ] 种子模板数据随启动幂等灌入（重复启动不产生重复条目）
- [ ] 生成流程中出现"正在检索模板"工具事件，且检索结果实际进入智能体上下文
- [ ] 画廊语义搜索命中相关应用（非关键词精确匹配）
- [ ] 已发布应用自动沉淀进知识库，之后的相关生成/搜索可受益
