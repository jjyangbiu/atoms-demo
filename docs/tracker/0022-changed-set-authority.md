# 0022 — 改动集权威来源归位（磁盘指纹比对）

**What to build:** 把「本轮改了哪些文件」的权威来源从「解析系统自己发给前端的流式事件」换成「磁盘轮前指纹与轮后指纹的比对」，沙箱侧同步记录本轮真实改动的文件集作为辅助。用户视角零变化：留档快照、迭代日志、无改动警告三处硬闸的行为与今天完全一致，只是判据变可信了——今天那条路径的参数摘要会截断超长字段，却握着这三重硬闸职责，是运气不是设计。这是后续自洽性核验与正确性裁判的地基：改动集本身若不可信，两层核验都建在沙上。遵循 ADR 0005「权威来源归位」段与规格 0021。

**Blocked by:** 无 — 可立即开工

**Status:** done

- [x] 轮前指纹取磁盘当前状态（路径 + 行数 + 内容哈希），轮末重算比对即得本轮真实改动文件集
- [x] 沙箱记录本轮真实改动的文件集，与既有的「本轮已读文件集」同构
- [x] 留档快照、迭代日志、无改动警告三处硬闸全部改由磁盘比对结果驱动，不再解析流式事件的参数字段
- [x] 流式事件行退回「给人看的过程记录」职责，不再兼任系统判据
- [x] 编辑失败、被闸门拒绝、零 diff 空操作均不计入改动集
- [x] ADR 0004 第 1–4 层工具闸门（禁止覆写已有文件、先读后改、替换文本四级定位、零 diff 空操作报错）原样保留，一行不动
- [x] 外部可观察行为与改动前完全一致：既有测试全绿，无需修改任何断言
- [x] 测试使用 fake 模型与沙箱单元接缝，覆盖改动集在成功编辑 / 失败编辑 / 空操作 / 多文件混合场景下的取值
