# 07 — 版本快照与回滚 + Monaco 代码视图

**What to build:** 每轮成功生成自动留下完整版本快照，用户可在版本历史抽屉中浏览并回滚到任意版本、然后在其基础上继续迭代；同时在项目页右侧提供"预览/代码"双 Tab——代码视图以 Monaco（只读）展示文件树与文件内容，让评审者能核查真实生成代码。

**Blocked by:** 04（对话迭代修改）

**Status:** done

- [x] 每次成功生成（首轮与迭代）后自动新增一条版本快照；历史列表按序可见
- [x] 回滚任一历史版本后当前文件恢复为该版本状态，后续迭代以其为基线
- [x] 快照保留最近 50 版，超出时最旧快照连同文件被清理
- [x] 项目页右侧"预览/代码"双 Tab 可切换；代码视图展示文件树与 Monaco 只读高亮内容
- [x] 只读约束生效：编辑器不可输入，且架构上预留后续开启编辑的配置位
