# 04 — 对话迭代修改

**What to build:** 生成不是终点：用户在已有应用上继续对话（"把按钮改大""加一个图表"），智能体基于当前文件清单与最近对话上下文做增量修改——只触碰受影响的文件，而非重传全量。迭代与首轮生成共用同一条聊天流与流式通道。

**Blocked by:** 03（工程师模式生成主链路）

**Status:** ready-for-agent

- [ ] 对已生成的项目发送修改指令，智能体仅修改受影响文件（伪模型测试断言未涉及文件内容不变）
- [ ] 迭代上下文携带：系统提示 + 当前文件清单 + 最近 N 条对话 + 当前指令
- [ ] 对话历史完整持久化，重新打开项目页可回看全部消息与工具事件
- [ ] 迭代完成后前端聊天流与项目状态无缝衔接，无需手动刷新页面
