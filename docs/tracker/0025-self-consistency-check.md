# 0025 — 自洽性核验上线，中文措辞正则机器退役

**What to build:** 「声称改完了但磁盘上什么都没变」从中文措辞正则打地鼠变成一次集合比较——比对模型声明改了什么与磁盘真实改了什么，确定性、无漏报、无误报、不需要穷举措辞。同时新增覆盖「偷偷改了却没申报」这一今天完全测不到的失配。失配时把精确差异回喂一次，仍失配则标注收尾。系统核验说明不再以文案形式追加进模型回复正文，改为卡片上的结构化徽标。工程师主提示删掉整条「严禁口头完成」（约 200 字），第 3、4 条压缩保留。这一步是 contract：0024 加完新出口后，旧的措辞守卫机器在此全部删除。遵循 ADR 0005「第 8 层」段与规格 0021 的退役清单。

**Blocked by:** 0024（核验的对象是终结出口的声明；新出口必须先存在）

**Status:** done

- [x] 声明有改动而磁盘零改动 → 判定为口头完成失配
- [x] 声明零改动而磁盘有改动 → 判定为未申报改动失配
- [x] 声明文件集与磁盘真实文件集不符 → 判定为文件集失配
- [x] 失配时把「你声明的 vs 磁盘实际的」精确差异回喂一次；仍失配则在卡片上标注收尾
- [x] 口头完成的固定短语表、正则族、三级升级链、「注入磁盘事实」的劝说式回喂全部删除；代码库中不再存在任何基于中文措辞的完成断言检测
- [x] 系统提示中「严禁口头完成」整条删除；「修改只能用编辑工具、替换文本必须唯一、只动受影响区域」保留但压缩（步数上限是硬预算，每次撞闸都是一个完整往返，告知比撞墙便宜）
