# 14 — 阿里云部署与线上验收

**What to build:** 把整套系统部署到阿里云 ECS，`http://{IP}` 对外可访问，并按验收冒烟脚本完成线上走查——这是"可测试的在线访问链接"交付物的落地。

验收冒烟脚本（即评审演示脚本）：注册 → 建项目（工程师模式）→ "做一个番茄钟" → 预览可用 → 迭代"加一个统计区" → 发布 → 隐身窗口打开 `/p/{slug}` → 另一账号克隆 → 继续迭代。

**Blocked by:** 13（Docker Compose 本地编排）+ **外部事实**：① 阿里云 ECS 购置（建议 ≥2C4G、Ubuntu 22.04/24.04）；② MiniMax API Key。两项就绪前本工单无法完成，但前置工单不受阻。

**Status:** ready-for-agent（等待外部事实）
