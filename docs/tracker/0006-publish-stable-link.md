# 06 — 发布与稳定链接

**What to build:** 用户一键发布项目，获得一个任何人无需登录即可访问的稳定公开链接（`/p/{slug}`）；此后每次迭代成功，公开链接内容自动更新而链接本身不变；也可取消发布撤回应用。项目页展示发布状态与链接，方便复制分享。

**Blocked by:** 04（对话迭代修改）、05（预览托管）

**Status:** done

- [x] 发布成功返回唯一稳定 slug，匿名（未登录）浏览器可访问公开链接并运行应用
- [x] 发布后继续迭代，公开链接不变且内容同步为最新版本
- [x] 取消发布后公开链接立即失效（404）
- [x] 一个项目同一时刻至多一条活跃发布记录；前端展示发布状态、公开链接与复制按钮
- [x] 非属主无法发布/取消发布他人项目

**安全备注（复审发现）：** 公开托管与主站同源，用户生成脚本可能窃取登录者凭据；已用 CSP `sandbox` 令公开文档获得不透明源作为即时缓解。彻底隔离需独立域名/端口托管，待部署工单（0013/0014）落地。
