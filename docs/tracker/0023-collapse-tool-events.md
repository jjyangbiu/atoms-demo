# 0023 — 工具调用记录默认折叠为轮次摘要

**What to build:** 用户读对话时不再被一条条工具调用记录淹没。同一轮的工具事件默认折叠成一行摘要（形如「本轮读取 N 个文件、修改 M 个文件」），点击展开可见完整明细；刷新页面后折叠摘要与明细保持一致。工具事件的落库契约不变——它们仍然是排查越界改动的证据链，变化只在渲染层。「对话被过程信息污染」这个痛点的本质从来不是这些信息存在，而是被平铺在对话主流里。遵循 ADR 0005「前端渲染」段与规格 0021。

**Blocked by:** 无 — 可立即开工（与 0022 并行；纯渲染层，随时可做、可独立回退）

**Status:** ready-for-agent

- [ ] 一轮内的多条工具事件在对话主流里折叠为一行摘要，摘要反映本轮真实的读取文件数与修改文件数
- [ ] 点击摘要可展开查看该轮完整的工具调用明细
- [ ] 刷新页面后历史回看与刷新前一致：折叠摘要 + 可展开明细
- [ ] 工具事件的落库行为与内容不变
- [ ] 思考过程的默认折叠现状不受影响
- [ ] 前端不做组件级测试（沿用规格 0001 的工期决策）；以端到端走查脚本覆盖折叠与展开，且类型检查构建通过
