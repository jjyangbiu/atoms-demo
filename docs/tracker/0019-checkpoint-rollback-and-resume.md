# 0019 — 检查点回滚与继续执行

**What to build:** 团队模式的检查点快照支持回滚：用户回滚到某个检查点后，项目文件恢复为该检查点状态，该检查点之后的工单状态重置为未完成。界面提供"继续执行"入口，由用户手动触发（不自动跑），工程师从第一个未完成工单按依赖顺序继续串行执行、继续生成新的检查点。回滚—续跑可反复进行。回滚与续跑不占用新的生成名额。遵循 ADR 0003。

**Blocked by:** 0018（没有检查点与执行机制无从回滚续跑）

**Status:** ready-for-agent

- [ ] 回滚到某检查点后文件状态与该检查点一致，其后工单重置为未完成
- [ ] "继续执行"入口仅在存在未完成工单时出现，由用户手动触发
- [ ] 续跑从第一个未完成工单开始，按依赖顺序执行并生成新检查点
- [ ] 回滚—续跑可多次反复，状态始终一致
- [ ] 回滚与续跑不重复占用生成名额
- [ ] 测试使用 fake 模型，覆盖回滚重置、续跑顺序与反复回滚的一致性
