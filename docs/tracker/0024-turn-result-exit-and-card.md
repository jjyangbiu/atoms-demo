# 0024 — 轮次产物终结出口与产物卡片

**What to build:** 一轮修改结束后，用户看到一张结构化卡片：一句话中文总结 + 本轮改了哪些文件 + 展开看本轮 diff 的入口。总结只经这个结构化出口产出，不再夹带「我先读了某文件、然后调用了编辑工具」这类过程复述。这一步是 expand：只加不删，模型若不走新出口仍按既有散文路径兜底收尾，所以既有集成测试无需改动即全绿。卡片上的改动文件清单以磁盘真实改动为权威（0022 的成果），不采信模型申报。遵循 ADR 0005「第 8 层」段与规格 0021。

**Blocked by:** 0022（卡片的改动清单必须取磁盘权威来源，不能沿用解析流式事件的老路）

**Status:** done

- [x] 工程师轮新增唯一终结出口，参数含：自报意图（改动代码 / 无需改动）、给用户看的中文总结（Markdown、简短）、声明改动的文件路径数组、无需改动时的理由
- [x] 出口以工具调用为载体，不使用 response_format（二者是互斥的输出通道：绑了工具还强制 JSON 输出，模型往往吐 JSON 而不调工具，循环直接断掉）
- [x] 智能体循环识别该出口为终结信号并结束本轮
- [x] 轮次产物以新的结构化消息类型落库，携带完整 payload
- [x] 前端把该消息渲染为卡片：一句话总结 + 改动文件清单 + 展开看本轮 diff
- [x] 声明改动只到文件级；区域级判断留给后续裁判，不要求模型自报行区间
- [x] 模型未调用出口时按既有散文路径兜底收尾；兜底路径下声明改动一律以磁盘真实值填充，绝不采信模型申报
- [x] 模型把产物 JSON 写进正文而没走工具时，按既有房规从后往前扫描候选起点恢复、解析失败补右括号重试
- [x] 自报「无需改动」可合法收尾、不触发任何惩罚（分类器只决定能力边界、不决定义务）
- [x] 首建轮与团队工单执行同样走这个出口（与迭代轮共用同一条工程师流路径，不单加开关）
- [x] 循环对模型实现的约定不变（可选流式、可选工具绑定、非流式回退），可编程伪模型仍走完全相同的代码路径
- [x] 测试使用 fake 模型，覆盖正常出口、正文 JSON 恢复、散文兜底三条路径；既有集成测试无需修改即全绿
